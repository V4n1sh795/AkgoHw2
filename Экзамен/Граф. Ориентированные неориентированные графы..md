Взвешенные/не взвешенные. Дерево. Степень вершины. Компонента связности. Достижимость одной вершины из другой. Путь. Простой путь. Цикл(Все предыдущее только определения). Способы хранения графов в компьютере.
### Определения
- **Взвешенный / невзвешенный граф**:
    - _Взвешенный граф_ — это граф, каждому ребру (или дуге) которого поставлено в соответствие некоторое числовое значение, называемое весом.
    - _Невзвешенный граф_ — это граф, ребрам (или дугам) которого не присвоены числовые значения (формально можно считать, что вес всех ребер равен 1).
- **Дерево** — это связный ациклический неориентированный граф. Эквивалентное определение: связный граф, в котором любые две вершины соединены ровно одним простым путем.
- **Степень вершины** — это количество ребер, инцидентных данной вершине. (В ориентированном графе различают _полустепень захода_ — количество входящих ребер, и _полустепень исхода_ — количество исходящих ребер).
- **Компонента связности** — это максимальный по включению связный подграф данного графа (то есть такой связный подграф, который не является частью никакого другого связного подграфа этого графа).
- **Достижимость одной вершины из другой** — вершина v называется достижимой из вершины u, если в графе существует путь, начинающийся в u и заканчивающийся в v.
- **Путь** — это конечная последовательность вершин и ребер вида, в которой каждое ребро  соединяет вершины .
- **Простой путь** — это путь, в котором все вершины (а следовательно, и все ребра) различны.
- **Цикл** — это путь, в котором начальная и конечная вершины совпадают. 
- **Простой цикл** — это цикл, в котором все вершины, кроме первой и последней, различны.
### Способы предстваления графов:
- **Матрица смежности (Adjacency Matrix)**
    - **Описание**: Двумерный массив (матрица) размером V×V (где V— количество вершин). Элемент A[i] [j]  равен 1 (или весу ребра), если существует ребро из вершины i в вершину j, и 0 в противном случае.
    - **Плюсы**: Быстрая проверка наличия ребра между двумя вершинами O(1).
    - **Минусы**: Требует O(V^2) памяти, что неэффективно для разреженных графов.
- **Списки смежности (Adjacency Lists)**
    - **Описание**: Массив (или хеш-таблица) размером V, где каждый элемент хранит список (или динамический массив) вершин, смежных с данной вершиной. Для взвешенных графов в списке хранятся пары `(соседняя_вершина, вес)`.
    - **Плюсы**: Эффективно по памяти для разреженных графов O(V+E), где E— количество ребер. Быстрый обход всех соседей вершины.
    - **Минусы**: Проверка наличия конкретного ребра требует O(степень вершины) времени.
- **Матрица инцидентности (Incidence Matrix)**
    - **Описание**: Двумерный массив размером V×E (вершины × ребра). Элемент равен 1, если вершина инцидентна ребру (для ориентированных графов: 1 для исходящего ребра, -1 для входящего, 0 иначе).
    - **Плюсы**: Удобна для некоторых теоретико-графовых задач и алгоритмов, работающих с потоками.
    - **Минусы**: Требует O(V×E) памяти, что на практике используется крайне редко из-за неэффективности.
- **Список ребер (Edge List)**
    - **Описание**: Простой массив или список, содержащий все ребра графа. Каждое ребро представлено парой вершин (u,v) а для взвешенных графов — тройкой (u,v,weight).
    - **Плюсы**: Максимально компактное хранение O(E) удобно для алгоритмов, которые обрабатывают ребра по одному (например, алгоритм Крускала).
    - **Минусы**: Очень медленный поиск смежных вершин или проверка наличия ребра O(E).
