Задача о рюкзаке. Два метода решения(динамическое программирование при небольших ограничениях на суммарный вес и полный перебор).

Задача о рюкзаке (в классической постановке **0/1**) формулируется так: дано $n$ предметов, каждый из которых имеет вес $w_i$ и стоимость $v_i$. Есть рюкзак вместимостью $W$. Необходимо выбрать подмножество предметов так, чтобы их суммарный вес не превышал $W$, а суммарная стоимость была максимальной. Каждый предмет можно взять либо 0, либо 1 раз.

Ниже подробно разобраны два запрошенных метода решения: полный перебор и динамическое программирование.

---

### 1. Полный перебор (Brute Force)

**Идея метода:**
Мы рассматриваем все возможные комбинации предметов. Для $n$ предметов существует ровно $2^n$ возможных подмножеств (каждый предмет можно либо взять, либо не взять). Для каждого подмножества мы проверяем, не превышает ли его вес вместимость рюкзака, и если нет — сравниваем его стоимость с текущим максимумом.

**Сложность:**
*   **Время:** $O(2^n)$ — экспоненциальная сложность.
*   **Память:** $O(n)$ — глубина стека вызовов при рекурсии.

**Когда применять:**
Только при очень малом количестве предметов ($n \le 20-25$). При $n=30$ количество операций уже превышает миллиард, что сделает вычисления неприемлемо долгими.

**Реализация на Python (рекурсивный подход):**

```python
def knapsack_bruteforce(weights, values, capacity, n):
    # Базовый случай: предметов нет или вместимость рюкзака равна 0
    if n == 0 or capacity == 0:
        return 0
    
    # Если вес текущего предмета больше оставшейся вместимости, мы не можем его взять
    if weights[n-1] > capacity:
        return knapsack_bruteforce(weights, values, capacity, n-1)
    
    # Иначе мы выбираем максимум из двух вариантов:
    # 1. Взять предмет (добавляем его стоимость и уменьшаем вместимость)
    # 2. Не брать предмет (просто переходим к следующему)
    else:
        return max(
            values[n-1] + knapsack_bruteforce(weights, values, capacity - weights[n-1], n-1),
            knapsack_bruteforce(weights, values, capacity, n-1)
        )

# Пример использования:
weights = [2, 3, 4, 5]
values = [3, 4, 5, 6]
capacity = 5
n = len(weights)

print("Максимальная стоимость (Перебор):", knapsack_bruteforce(weights, values, capacity, n)) 
# Ответ: 7 (предметы с весом 2 и 3, стоимостью 3 и 4)
```

### 2. Динамическое программирование (Dynamic Programming)

**Идея метода:**
Вместо многократного пересчета одних и тех же подзадач (как это делает рекурсия в полном переборе), мы запоминаем результаты. 
Мы создаем массив `dp`, где `dp[w]` хранит максимальную стоимость, которую можно набрать при ограничении по весу ровно `w`. Мы последовательно рассматриваем каждый предмет и обновляем массив `dp`.

*Важный нюанс:* чтобы не взять один и тот же предмет несколько раз (что превратило бы задачу в задачу о неограниченном рюкзаке), внутренний цикл по весу нужно проходить **в обратном порядке** (от $W$ до $w_i$).

**Сложность:**
*   **Время:** $O(n \times W)$ — псевдополиномиальная сложность.
*   **Память:** $O(W)$ — при использовании оптимизации до одномерного массива (вместо двумерной таблицы $n \times W$).

**Когда применять:**
Когда количество предметов $n$ может быть большим (сотни или тысячи), но **ограничение на вес $W$ относительно небольшое** (например, $W \le 10^5$). Если $W$ огромно (например, $10^9$), этот метод потребует слишком много памяти и времени, и тогда нужны другие подходы (например, метод ветвей и границ).

**Реализация на Python (с оптимизацией памяти):**

```python
def knapsack_dp(weights, values, capacity, n):
    # dp[w] будет хранить максимальную стоимость для веса w
    # Инициализируем массив нулями
    dp = [0] * (capacity + 1)
    
    # Проходим по всем предметам
    for i in range(n):
        # Проходим по весам в обратном порядке, чтобы не использовать предмет i дважды
        for w in range(capacity, weights[i] - 1, -1):
            # Выбираем: не брать предмет (dp[w]) или взять его (dp[w - weights[i]] + values[i])
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
            
    # Ответ находится в ячейке для максимальной вместимости
    return dp[capacity]

# Пример использования:
weights = [2, 3, 4, 5]
values = [3, 4, 5, 6]
capacity = 5
n = len(weights)

print("Максимальная стоимость (ДП):", knapsack_dp(weights, values, capacity, n)) 
# Ответ: 7
```

### Сравнительная таблица методов

| Характеристика | Полный перебор | Динамическое программирование |
| :--- | :--- | :--- |
| **Зависимость времени** | От количества предметов $O(2^n)$ | От количества предметов и веса $O(n \times W)$ |
| **Зависимость памяти** | $O(n)$ (стек вызовов) | $O(W)$ (одномерный массив) |
| **Идеальные условия** | $n \le 25$, вес $W$ может быть любым (даже огромным) | $n$ может быть большим, но вес $W$ небольшой (например, $\le 10^5$) |
| **Главный недостаток** | Неприменим при $n > 30$ из-за экспоненциального роста времени | Неприменим при огромных $W$ (например, $10^9$) из-за нехватки памяти |

**Совет:** На практике, если ограничения не позволяют использовать ни один из этих двух методов (например, и $n=1000$, и $W=10^9$), задачу решают с помощью **метода ветвей и границ** (Branch and Bound) или применяют **приближенные алгоритмы** (жадные алгоритмы или Fully Polynomial Time Approximation Scheme - FPTAS), которые находят решение, очень близкое к оптимальному, за разумное время.
