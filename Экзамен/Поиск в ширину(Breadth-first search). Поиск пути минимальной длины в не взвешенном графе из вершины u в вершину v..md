Поиск в ширину (Breadth-First Search, BFS) — это фундаментальный алгоритм обхода графа, который гарантирует нахождение **кратчайшего пути** (в смысле минимального количества ребер) между двумя вершинами в **невзвешенном графе**.
### Почему BFS находит кратчайший путь?
Алгоритм исследует граф "слоями". Сначала он посещает все вершины на расстоянии 1 ребра от старта, затем все вершины на расстоянии 2 ребер, затем 3 и так далее. Благодаря этому свойству, когда мы впервые достигаем целевой вершины $v$, мы гарантированно делаем это по пути с минимальным количеством ребер.
### Алгоритм (пошагово)

Для решения задачи нам понадобятся следующие структуры данных:
1. **Очередь (Queue)**: для хранения вершин, которые нужно обработать (принцип FIFO: первый вошел, первый вышел).
2. **Массив `distance`**: для хранения минимального расстояния от стартовой вершины $u$ до каждой вершины (изначально заполнен `-1` или бесконечностью).
3. **Массив `parent`**: для восстановления самого пути. Хранит информацию о том, из какой вершины мы пришли в текущую.
4. **Множество или массив `visited`**: для отметки посещенных вершин (чтобы избежать зацикливания). В массиве `distance` значение `-1` уже может выполнять эту роль.

**Шаги алгоритма:**
1. Инициализируем `distance[u] = 0`, помещаем вершину $u$ в очередь.
2. Пока очередь не пуста:
   - Извлекаем вершину `curr` из начала очереди.
   - Если `curr == v`, мы нашли цель (можно досрочно завершить поиск для оптимизации).
   - Для каждого соседа `neighbor` вершины `curr`:
     - Если `distance[neighbor] == -1` (вершина еще не посещена):
       - `distance[neighbor] = distance[curr] + 1`
       - `parent[neighbor] = curr`
       - Добавляем `neighbor` в конец очереди.
1. **Восстановление пути**: Если `distance[v] != -1`, начинаем с вершины $v$ и двигаемся по массиву `parent` назад до вершины $u$. Полученный список вершин нужно развернуть, чтобы получить путь от $u$ к $v$.
### Реализация на Python

```python
from collections import deque

def bfs_shortest_path(graph, u, v):
    # Инициализация
    distance = {node: -1 for node in graph}
    parent = {node: None for node in graph}
    
    distance[u] = 0
    queue = deque([u])
    
    while queue:
        curr = queue.popleft()
        
        # Оптимизация: если достигли цели, можно остановиться
        if curr == v:
            break
            
        for neighbor in graph[curr]:
            if distance[neighbor] == -1:  # Если сосед еще не посещен
                distance[neighbor] = distance[curr] + 1
                parent[neighbor] = curr
                queue.append(neighbor)
                
    # Если до вершины v добраться невозможно
    if distance[v] == -1:
        return -1, []
        
    # Восстановление пути от v к u
    path = []
    current_node = v
    while current_node is not None:
        path.append(current_node)
        current_node = parent[current_node]
        
    # Разворачиваем путь, чтобы он шел от u к v
    path.reverse()
    
    return distance[v], path

# === Пример использования ===
if __name__ == "__init__":
    # Граф в виде списка смежности (невзвешенный, неориентированный)
    #   0 -- 1 -- 3
    #   |    |
    #   2 -- 4
    graph = {
        0: [1, 2],
        1: [0, 3, 4],
        2: [0, 4],
        3: [1],
        4: [1, 2]
    }
    
    start_node = 0
    target_node = 3
    
    length, path = bfs_shortest_path(graph, start_node, target_node)
    
    print(f"Кратчайшее расстояние: {length}")
    print(f"Путь: {' -> '.join(map(str, path))}")
    # Вывод:
    # Кратчайшее расстояние: 2
    # Путь: 0 -> 1 -> 3
```

### Оценка сложности
- **Временная сложность**: $O(V + E)$, где $V$ — количество вершин, $E$ — количество ребер. Каждая вершина и каждое ребро обрабатываются не более одного раза.
- **Пространственная сложность**: $O(V)$ для хранения очереди, массивов `distance` и `parent`.
### Важные нюансы
1. **Ориентированный vs Неориентированный граф**: Алгоритм работает одинаково хорошо для обоих типов графов, если список смежности построен корректно.
2. **Взвешенные графы**: Если граф взвешенный (ребра имеют разную стоимость), BFS **не гарантирует** нахождение кратчайшего пути. Для таких случаев используется алгоритм Дейкстры (Dijkstra) или A*.
3. **Ранний выход**: Проверка `if curr == v: break` значительно ускоряет работу на больших графах, так как алгоритм не будет обходить весь граф, если цель уже найдена.
