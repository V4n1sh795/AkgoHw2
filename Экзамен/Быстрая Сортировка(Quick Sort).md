Быстрая Сортировка(Quick Sort). Время работы в худшем случае и в лучшем(ожидаемое не надо).
### Описание алгоритма:
1. **Выбор опорного элемента (Pivot):** Из массива выбирается один элемент. Это может быть первый, последний, средний элемент или случайный элемент (выбор случайного элемента помогает избежать худшего случая O(n2)\mathcal{O}(n^2)O(n2)).
2. **Разбиение (Partition):** Массив перестраивается так, чтобы все элементы, **меньшие** опорного, оказались слева от него, а все элементы, **большие** опорного, оказались справа. Элементы, равные опорному, могут находиться в любой из частей (или в выделенной центральной части). После этого шага опорный элемент оказывается на своем окончательном, отсортированном месте.
3. **Рекурсия:** Шаги 1 и 2 рекурсивно применяются к левой и правой частям массива (подмассивам).
4. **Базовый случай рекурсии:** Рекурсия останавливается, когда размер подмассива равен 0 или 1 (такой массив уже считается отсортированным).
**Лучший случай: O(nlog⁡n)**
	Когда возникает: Опорный элемент (pivot) каждый раз делит текущий массив на две примерно равные части. В этом случае глубина рекурсии составляет log⁡n, а на каждом уровне рекурсии выполняется O(n) операций сравнения и обмена.

**Худший случай: O(n^2)**
	Когда возникает: Опорный элемент каждый раз оказывается наименьшим или наибольшим элементом подмассива. Это приводит к максимально несбалансированному разделению (одна часть имеет размер 000, другая n−1. Глубина рекурсии становится равной n, что в сумме дает O(n^2) операций. Классический пример: уже отсортированный (или отсортированный в обратном порядке) массив, при условии, что опорным элементом всегда выбирается первый или последний элемент.
#### Реализация:
```python
def quick_sort_simple(arr):
    # Базовый случай: массив из 0 или 1 элемента уже отсортирован
    if len(arr) <= 1:
        return arr
    
    # Выбираем опорный элемент (например, средний)
    pivot = arr[len(arr) // 2]
    
    # Разбиваем массив на три части
    left = [x for x in arr if x < pivot]    # Меньше опорного
    middle = [x for x in arr if x == pivot] # Равные опорному
    right = [x for x in arr if x > pivot]   # Больше опорного
    
    # Рекурсивно сортируем левую и правую части и объединяем
    return quick_sort_simple(left) + middle + quick_sort_simple(right)

# Пример использования:
data = [3, 6, 8, 10, 1, 2, 1]
print(quick_sort_simple(data))  # Вывод: [1, 1, 2, 3, 6, 8, 10]
```
