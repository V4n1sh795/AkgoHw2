Префикс Функция. Поиск подстроки в строке за линейное время.
Префикс-функция — это ключевой элемент **алгоритма Кнута — Морриса — Пратта (КМП)**, который позволяет находить все вхождения подстроки (образца) в строку (текст) за линейное время $O(N + M)$, где $N$ — длина текста, а $M$ — длина образца.
Ниже приведено подробное объяснение того, как она работает, как её вычислять и как использовать для поиска.
### 1. Определение префикс-функции

Для строки $S$ префикс-функция $\pi[i]$ определяется как **длина наибольшего собственного префикса** подстроки $S[0 \dots i]$, который одновременно является и **суффиксом** этой подстроки.

*   *Собственный префикс* означает, что длина этого префикса должна быть строго меньше длины самой подстроки (то есть $\pi[i] \le i$).
*   $\pi[0]$ всегда равно $0$, так как у строки длины 1 нет собственных префиксов.
**Пример:**
Для строки $S = \text{"abacabad"}$:
- $i=0$, $S[0\dots0] = \text{"a"}$, $\pi[0] = 0$
- $i=1$, $S[0\dots1] = \text{"ab"}$, $\pi[1] = 0$
- $i=2$, $S[0\dots2] = \text{"aba"}$, $\pi[2] = 1$ (префикс "a" = суффикс "a")
- $i=3$, $S[0\dots3] = \text{"abac"}$, $\pi[3] = 0$
- $i=4$, $S[0\dots4] = \text{"abaca"}$, $\pi[4] = 1$
- $i=5$, $S[0\dots5] = \text{"abacab"}$, $\pi[5] = 2$ (префикс "ab" = суффикс "ab")
- $i=6$, $S[0\dots6] = \text{"abacaba"}$, $\pi[6] = 3$ (префикс "aba" = суффикс "aba")
- $i=7$, $S[0\dots7] = \text{"abacabad"}$, $\pi[7] = 0$

Массив $\pi$: `[0, 0, 1, 0, 1, 2, 3, 0]`
### 2. Алгоритм вычисления префикс-функции за $O(M)$
**Идея:** При вычислении $\pi[i]$ мы уже знаем $\pi[i-1]$. Мы пытаемся продолжить наибольший подходящий префикс/суффикс предыдущей подстроки. Если символы не совпадают, мы "откатываемся" к следующему по длине подходящему префиксу, используя значение $\pi[\pi[i-1]-1]$, и так далее, пока не найдем совпадение или не дойдем до 0.

```python
def prefix_function(s: str) -> list[int]:
    n = len(s)
    pi = [0] * n
    for i in range(1, n):
        j = pi[i - 1]
        # Пока есть что откатывать и символы не совпадают
        while j > 0 and s[i] != s[j]:
            j = pi[j - 1]
        # Если символы совпали, увеличиваем длину текущего префикса
        if s[i] == s[j]:
            j += 1
        pi[i] = j
    return pi
```
*Сложность:* $O(M)$, так как переменная `j` увеличивается не более чем на 1 на каждой итерации цикла `for`, а в цикле `while` она только уменьшается. Суммарное число уменьшений не может превысить суммарное число увеличений.
### 3. Поиск подстроки в строке за $O(N + M)$
Чтобы найти все вхождения образца $P$ (длины $M$) в текст $T$ (длины $N$), мы используем следующий трюк:
1. Создаем новую строку $S = P + \text{'\#'} + T$, где `'#'` — это специальный символ-разделитель, который **гарантированно не встречается** ни в $P$, ни в $T$. Он нужен, чтобы префикс-функция не "перепрыгнула" из текста обратно в образец.
2. Вычисляем префикс-функцию для строки $S$.
3. Проходим по второй половине массива $\pi$ (которая соответствует тексту $T$). Если для какого-то индекса $i$ выполняется условие $\pi[i] == M$, это означает, что мы нашли полное совпадение образца $P$.
**Как найти индекс начала вхождения в исходном тексте $T$?**
Если совпадение заканчивается на индексе $i$ в строке $S$, то оно начинается на индексе $i - M + 1$ в строке $S$. Поскольку текст $T$ начинается в $S$ с индекса $M + 1$ (после образца длины $M$ и разделителя), индекс начала вхождения в самом тексте $T$ будет равен:
$$ \text{index\_in\_T} = (i - M + 1) - (M + 1) = i - 2M $$
**Пример кода для поиска:**

```python
def kmp_search(pattern: str, text: str) -> list[int]:
    m = len(pattern)
    n = len(text)
    
    # Специальный символ, которого нет в алфавите
    separator = '#'
    
    # Формируем объединенную строку
    s = pattern + separator + text
    
    # Вычисляем префикс-функцию
    pi = prefix_function(s)
    
    occurrences = []
    # Проверяем только часть, соответствующую тексту
    for i in range(m + 1, len(s)):
        if pi[i] == m:
            # Вычисляем индекс начала вхождения в тексте T
            start_index = i - 2 * m
            occurrences.append(start_index)
            
    return occurrences

# Пример использования:
text = "abacabacabad"
pattern = "abacaba"
print(kmp_search(pattern, text)) 
# Вывод: [0, 4] (вхождения начинаются с индексов 0 и 4)
```
### 4. Оценка сложности

- **Временная сложность:** $O(N + M)$. Построение строки $S$ занимает $O(N + M)$, вычисление префикс-функции также строго $O(N + M)$ благодаря амортизированному анализу цикла `while`.
- **Пространственная сложность:** $O(N + M)$ для хранения объединенной строки и массива $\pi$. 
  *(Примечание: если текст $T$ подается потоком или очень велик, можно вычислять префикс-функцию "на лету", храня в памяти только массив $\pi$ размера $O(M)$ и текущий символ текста, что снизит потребление памяти до $O(M)$).*
### Почему это работает?
Главная сила префикс-функции в том, что она **исключает возвраты по тексту**. В наивном алгоритме при несовпадении мы сдвигаем образец на 1 и начинаем сравнение заново. Префикс-функция заранее знает, какая часть образца уже гарантированно совпадает с текстом благодаря предыдущим сравнениям, и позволяет продолжить проверку с нужного места, не перечитывая символы текста.
