Z-функция. Поиск подстроки в строке за линейное время.
Является альтернативой префикс-функции из алгоритма Кнута-Морриса-Пратта (KMP).
Для строки S длины n **Z-функция** — это массив Z длины n, где элемент Z[i] равен длине наибольшего общего префикса строки S и суффикса строки S, начинающегося в позиции i.
Проще говоря, Z[i]показывает, сколько первых символов строки S совпадают с символами, начинающимися с позиции i. _Принято считать, что Z[0]=0_ (хотя формально вся строка является своим префиксом, обнуление упрощает алгоритм поиска).
**Пример:** Для строки S="abacaba"
- Z[0]=0
- Z[1]=0 ("b..." не совпадает с "a...")
- Z[2]=1 ("a" совпадает с "a")
- Z[3]=0 ("c..." не совпадает с "a...")
- Z[4]=3 ("aba" совпадает с "aba")
- Z[5]=0
- Z[6]=1 ("a" совпадает с "a")
- Итоговый массив: `[0, 0, 1, 0, 3, 0, 1]`
### Алгоритм вычисления Z-функции за O(N)
- l и r — это границы самого правого (с максимальным r) найденного на данный момент подотрезка, который совпадает с префиксом строки.
- Изначально l=0,r=0.
При переборе индекса i от 1 до n−1:
1. Если i≤r, мы уже знаем, что подстрока S[i…r] совпадает с префиксом S[0…r−i]. Следовательно, мы можем инициализировать Z[i]=min⁡(r−i+1,Z[i−l]). Это позволяет избежать повторных сравнений уже известных символов.
2. После этой инициализации мы пытаемся увеличить Z[i], посимвольно сравнивая S[Z[i]]и S[i+Z[i]].
3. Если в результате i+Z[i]−1>r, мы обновляем границы нашего самого правого Z-блока: l=i, r=i+Z[i]−1.

```python
def z_function(s: str) -> list[int]:
    n = len(s)
    z = [0] * n
    l, r = 0, 0
    for i in range(1, n):
        if i <= r:
            z[i] = min(r - i + 1, z[i - l])
        # Пытаемся увеличить z[i] посимвольным сравнением
        while i + z[i] < n and s[z[i]] == s[i + z[i]]:
            z[i] += 1
        # Обновляем правую границу Z-блока, если удалось его расширить
        if i + z[i] - 1 > r:
            l, r = i, i + z[i] - 1
    return z```
