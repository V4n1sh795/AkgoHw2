Структура данных Бинарное Дерево Поиска(Binary Search Tree). Основные операции.
### 1. Основные свойства
Бинарное дерево поиска удовлетворяет следующим условиям для **каждого** узла:
1. Все значения в **левом поддереве** строго **меньше** значения текущего узла.
2. Все значения в **правом поддереве** строго **больше** значения текущего узла.
3. Левое и правое поддеревья сами по себе также являются бинарными деревьями поиска.
4. Дубликаты значений обычно не допускаются (или обрабатываются особым образом, например, хранятся в счетчике или всегда идут в правое поддерево).
### 2. Основные операции
#### Поиск (Search)
- **Алгоритм**: Начинаем с корня. Если искомое значение равно значению узла, поиск завершен. Если оно меньше, переходим в левое поддерево; если больше — в правое. Повторяем, пока не найдем элемент или не достигнем пустого узла (`null`).
- **Сложность**: O(log⁡n)в среднем, O(n)в худшем случае.
#### Вставка (Insert)
- **Алгоритм**: Работает аналогично поиску. Мы спускаемся по дереву, сравнивая значение, пока не найдем пустое место (`null`), куда и помещаем новый узел.
- **Сложность**: O(log⁡n) в среднем, O(n) в худшем случае.
#### Удаление (Delete)
Удаление — самая сложная операция. Существует три случая:
1. **Узел является листом** (нет детей): просто удаляем его.
2. **Узел имеет одного ребенка**: заменяем удаляемый узел его единственным ребенком.
3. **Узел имеет двух детей**: находим **наименьший элемент в правом поддереве** (или наибольший в левом) — он называется _преемником_ (in-order successor). Копируем значение преемника в удаляемый узел, а затем рекурсивно удаляем сам узел-преемник (у которого максимум один ребенок, сводя задачу к случаю 1 или 2).
- **Сложность**: O(log⁡n) в среднем, O(n) в худшем случае.
#### Обход (Traversal)
- **In-order (Симметричный)**: Левое поддерево → Узел → Правое поддерево. **Важно:** для БДП этот обход всегда возвращает элементы в **отсортированном (возрастающем) порядке**.
- **Pre-order (Прямой)**: Узел → Левое поддерево → Правое поддерево (полезен для копирования дерева).
- **Post-order (Обратный)**: Левое поддерево → Правое поддерево → Узел (полезен для безопасного удаления дерева).
