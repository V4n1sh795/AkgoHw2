Структура данных Бинарная Куча(Binary Heap). Основные операции. Сортировка кучей(Heap Sort).
**Бинарная куча (Binary Heap)** — это структура данных, представляющая собой полное бинарное дерево, которое удовлетворяет свойству кучи. Она широко используется для реализации приоритетных очередей и в алгоритме пирамидальной сортировки (Heap Sort).
1. **Свойство формы (Shape Property):** Куча является _полным_ бинарным деревом. Все уровни дерева полностью заполнены, за исключением, возможно, последнего уровня, который заполняется слева направо без пропусков.
2. **Свойство кучи (Heap Property):**
    - **Максимальная куча (Max-Heap):** Значение каждого узла больше или равно значениям его дочерних узлов. (Корень содержит максимальный элемент).
    - **Минимальная куча (Min-Heap):** Значение каждого узла меньше или равно значениям его дочерних узлов. (Корень содержит минимальный элемент).
#### Представление в виде массива
Благодаря свойству формы, кучу очень эффективно хранить в обычном массиве (без указателей на детей). При индексации с `0`:
- Левый ребенок узла с индексом `i`: `2 * i + 1`
- Правый ребенок узла с индексом `i`: `2 * i + 2`
- Родитель узла с индексом `i`: `(i - 1) // 2` (целочисленное деление)
### 2. Основные операции
#### А. Вставка элемента (Insert / Push)
- **Алгоритм:**
    1. Добавляем новый элемент в конец массива (на первый свободный уровень дерева).
    2. Выполняем операцию **всплытия (sift-up / heapify-up)**: сравниваем элемент с его родителем. Если свойство кучи нарушено (например, в Max-Heap дочерний элемент больше родительского), меняем их местами. Повторяем, пока свойство не восстановится или не достигнем корня.
- **Сложность:** O(log⁡n), где n — количество элементов.
#### Б. Извлечение максимума/минимума (Extract Max / Min)
- **Алгоритм:**
    1. Сохраняем значение корня (это и есть искомый максимум/минимум).
    2. Заменяем корень последним элементом массива (последним листом дерева).
    3. Удаляем последний элемент из массива.
    4. Выполняем операцию **просеивания вниз (sift-down / heapify-down)**: сравниваем новый корень с его детьми. Если свойство кучи нарушено, меняем его местами с _наибольшим_ (для Max-Heap) или _наименьшим_ (для Min-Heap) из детей. Повторяем рекурсивно вниз по дереву.
- **Сложность:** O(log⁡n)
#### В. Построение кучи из неупорядоченного массива (Build Heap)
- **Алгоритм:**
    1. Начинаем с последнего нелистового узла (его индекс `(n // 2) - 1`).
    2. Применяем операцию _просеивания вниз (heapify-down)_ к этому узлу и двигаемся к корню (индекс 0).
- **Сложность:** O(n)O(n)O(n). _Важно:_ Хотя heapify работает за O(log⁡n)O(\log n)O(logn), математический анализ показывает, что суммарная сложность построения кучи линейна, так как большинство узлов находятся на нижних уровнях и требуют мало перестановок.
#### Г. Получение максимума/минимума без удаления (Peek)
- **Алгоритм:** Просто вернуть элемент с индексом `0`.
- **Сложность:** O(1)O(1)O(1).
### 3. Сортировка кучей (Heap Sort / Пирамидальная сортировка)
Heap Sort использует свойства Max-Heap для сортировки массива по возрастанию. Алгоритм работает _in-place_ (на месте), не требуя дополнительной памяти.
#### Алгоритм:
1. **Построение кучи:** Преобразуем исходный неупорядоченный массив в Max-Heap (используя операцию Build Heap). Теперь максимальный элемент находится в корне (индекс 0).
2. **Сортировка:**
    - Меняем местами корень (максимальный элемент) с последним элементом текущей кучи.
    - Уменьшаем размер рассматриваемой кучи на 1 (максимальный элемент теперь находится на своем окончательном месте в конце массива и исключается из кучи).
    - Применяем операцию _просеивания вниз (heapify-down)_ к новому корню, чтобы восстановить свойство Max-Heap для оставшихся элементов.
    - Повторяем эти шаги, пока размер кучи не станет равен 1.
```python
def heapify(arr, n, i):
    """Просеивание вниз для поддержания свойства Max-Heap."""
    largest = i          # Инициализируем наибольший элемент как корень
    left = 2 * i + 1     # Левый ребенок
    right = 2 * i + 2    # Правый ребенок

    # Если левый ребенок существует и больше корня
    if left < n and arr[left] > arr[largest]:
        largest = left

    # Если правый ребенок существует и больше текущего наибольшего
    if right < n and arr[right] > arr[largest]:
        largest = right

    # Если наибольший элемент не корень, меняем их местами и просеиваем дальше
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)

def heap_sort(arr):
    n = len(arr)

    # Шаг 1: Построение Max-Heap (начинаем с последнего нелистового узла)
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)

    # Шаг 2: Поочередное извлечение элементов из кучи
    for i in range(n - 1, 0, -1):
        # Меняем текущий корень (максимум) с последним элементом
        arr[i], arr[0] = arr[0], arr[i]
        # Вызываем heapify для уменьшенной кучи (размер i)
        heapify(arr, i, 0)
        
    return arr

# Пример использования
data = [12, 11, 13, 5, 6, 7]
print("Отсортированный массив:", heap_sort(data))
# Вывод: [5, 6, 7, 11, 12, 13]

```
#### Преимущества:

- Гарантированная временная сложность O(nlog⁡n) в худшем случае (в отличие от Quick Sort, который может деградировать до O(n^2).
- Не требует дополнительной памяти O(1).
- Отлично подходит для нахождения K наибольших/наименьших элементов (через структуру данных Priority Queue).
#### Недостатки:
- На практике часто работает медленнее, чем Quick Sort или Merge Sort, из-за плохой локальности ссылок (cache misses) при обращении к элементам массива при просеивании.
- Нестабильна.
### Резюме
Бинарная куча — это фундаментальная структура, обеспечивающая быстрый доступ к экстремальным значениям O(1) и их удаление O(log⁡n). Heap Sort является элегантным применением этой структуры, предлагающим надежную сортировку за O(nlog⁡n) с минимальными требованиями к памяти.
