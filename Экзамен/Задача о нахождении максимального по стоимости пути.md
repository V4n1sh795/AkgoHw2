
Задача о нахождении максимального по стоимости пути из левой верхней клетки в правую нижнюю в таблице, при возможности ходить только вправо и вниз. Решение методом динамического программирования.
Задача о нахождении максимального по стоимости пути из левого верхнего угла `(0, 0)` в правый нижний `(m-1, n-1)` при движениях только **вправо** и **вниз** является классическим примером применения динамического программирования (ДП).

Ниже приведено полное руководство: от математической формулировки до готового кода на Python с восстановлением самого пути.

---

### 1. Идея динамического программирования
Задача обладает двумя ключевыми свойствами для применения ДП:
1. **Оптимальная подструктура:** Максимальный путь до клетки `(i, j)` складывается из стоимости самой клетки `(i, j)` и максимума из двух возможных путей, ведущих к ней: сверху `(i-1, j)` или слева `(i, j-1)`.
2. **Перекрывающиеся подзадачи:** При рекурсивном переборе мы многократно вычисляем стоимость пути до одних и тех же клеток. ДП позволяет сохранить эти значения и использовать их повторно.

### 2. Математическая формулировка
Пусть `dp[i][j]` — это максимальная стоимость пути до клетки в строке `i` и столбце `j`.

**Базовый случай:**
* `dp[0][0] = grid[0][0]` (стоимость стартовой клетки).

**Граничные условия:**
* Для первой строки (`i = 0`) мы можем прийти только слева:  
  `dp[0][j] = dp[0][j-1] + grid[0][j]`
* Для первого столбца (`j = 0`) мы можем прийти только сверху:  
  `dp[i][0] = dp[i-1][0] + grid[i][0]`

**Рекуррентное соотношение (для остальных клеток):**
* `dp[i][j] = grid[i][j] + max(dp[i-1][j], dp[i][j-1])`

---

### 3. Реализация на Python (с восстановлением пути)
Часто требуется не только найти максимальную сумму, но и вывести сам путь. Для этого мы сначала заполняем таблицу `dp`, а затем движемся от конца к началу, выбирая клетку, из которой мы пришли.

```python
def max_cost_path(grid):
    if not grid or not grid[0]:
        return 0, []

    m = len(grid)      # количество строк
    n = len(grid[0])   # количество столбцов

    # 1. Создаем таблицу DP того же размера, что и grid
    dp = [[0] * n for _ in range(m)]
    
    # 2. Заполняем базовый случай
    dp[0][0] = grid[0][0]
    
    # 3. Заполняем первую строку (можно прийти только слева)
    for j in range(1, n):
        dp[0][j] = dp[0][j-1] + grid[0][j]
        
    # 4. Заполняем первый столбец (можно прийти только сверху)
    for i in range(1, m):
        dp[i][0] = dp[i-1][0] + grid[i][0]
        
    # 5. Заполняем остальную таблицу
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = grid[i][j] + max(dp[i-1][j], dp[i][j-1])
            
    # 6. Восстановление пути (Backtracking)
    path = []
    i, j = m - 1, n - 1
    path.append((i, j))
    
    while i > 0 or j > 0:
        # Если мы в первой строке, можем двигаться только влево
        if i == 0:
            j -= 1
        # Если мы в первом столбце, можем двигаться только вверх
        elif j == 0:
            i -= 1
        # Иначе выбираем направление, откуда пришла максимальная стоимость
        elif dp[i-1][j] > dp[i][j-1]:
            i -= 1  # пришли сверху
        else:
            j -= 1  # пришли слева
            
        path.append((i, j))
        
    # Путь собран от конца к началу, переворачиваем его
    path.reverse()
    
    # Преобразуем координаты в значения для наглядности
    path_values = [grid[r][c] for r, c in path]

    return dp[m-1][n-1], path_values, path

# --- Пример использования ---
grid = [
    [1, 3, 1],
    [1, 5, 1],
    [4, 2, 1]
]

max_sum, values, coords = max_cost_path(grid)

print(f"Максимальная стоимость пути: {max_sum}")
print(f"Значения на пути: {values}")
print(f"Координаты пути: {coords}")
```

**Вывод программы:**
```text
Максимальная стоимость пути: 12
Значения на пути: [1, 3, 5, 2, 1]
Координаты пути: [(0, 0), (0, 1), (1, 1), (2, 1), (2, 2)]
```

### 4. Анализ сложности
* **Временная сложность:** $O(m \times n)$, где $m$ и $n$ — размеры матрицы. Мы проходим по каждой клетке ровно один раз.
* **Пространственная сложность:** $O(m \times n)$ для хранения таблицы `dp` и восстановления пути. 

### 5. Оптимизация памяти (до $O(n)$)
Если вам нужна **только максимальная сумма** (без восстановления самого пути), можно заметить, что для вычисления текущей строки `dp[i]` нам нужны значения только из предыдущей строки `dp[i-1]` и текущей строки `dp[i]`. 

Поэтому вместо двумерной матрицы можно использовать одномерный массив длиной `n` (количество столбцов):

```python
def max_cost_path_optimized(grid):
    if not grid or not grid[0]:
        return 0
    
    n = len(grid[0])
    dp = [0] * n
    dp[0] = grid[0][0]
    
    # Инициализация первой строки
    for j in range(1, n):
        dp[j] = dp[j-1] + grid[0][j]
        
    # Обработка остальных строк
    for i in range(1, len(grid)):
        # Первый элемент строки может прийти только сверху
        dp[0] += grid[i][0]
        for j in range(1, n):
            # dp[j] (до обновления) - это значение сверху (из предыдущей строки)
            # dp[j-1] (уже обновленное) - это значение слева (из текущей строки)
            dp[j] = grid[i][j] + max(dp[j], dp[j-1])
            
    return dp[-1]
```
Этот вариант требует всего $O(n)$ дополнительной памяти, что критически важно при работе с огромными матрицами.
