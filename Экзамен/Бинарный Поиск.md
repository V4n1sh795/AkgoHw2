*Алгоритм бинарного поиска. Бинарный поиск в массиве и бинарный поиск по ответу.*
    **Алгоритм:**
	Инициализируем два указателя: `left = 0` и `right = len(arr) - 1`.
	Пока `left <= right`:
	    - Вычисляем средний индекс: `mid = left + (right - left) // 2` (такая формула защищает от переполнения в языках вроде C++/Java, в Python можно писать просто `(left + right) // 2`).
	    - Если `arr[mid] == target`, мы нашли элемент, возвращаем `mid`.
	    - Если `arr[mid] < target`, искомый элемент находится правее, сдвигаем `left = mid + 1`.
	    - Если `arr[mid] > target`, искомый элемент находится левее, сдвигаем `right = mid - 1`.
	Поиск по ответу аналогичен, если функция ответов монотонная
