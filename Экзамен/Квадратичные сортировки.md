
### 1. Сортировка Пузырьком (Bubble Sort)

**Принцип работы:**  
Алгоритм многократно проходит по массиву, сравнивая соседние элементы. Если левый элемент больше правого (при сортировке по возрастанию), они меняются местами. В результате каждого полного прохода самый большой («тяжелый») элемент «всплывает» в конец массива, как пузырек в воде.

**Оптимизация:**  
Можно добавить флаг `swapped`. Если за весь проход не было ни одной перестановки, значит, массив уже отсортирован, и алгоритм можно досрочно завершить.

**Характеристики:**
*   **Лучшее время:** $O(n)$ (если массив уже отсортирован и используется флаг `swapped`)
*   **Среднее время:** $O(n^2)$
*   **Худшее время:** $O(n^2)$ (массив отсортирован в обратном порядке)
*   **Память:** $O(1)$ (сортировка на месте)
*   **Устойчивость:** Да (относительный порядок равных элементов не меняется)

**Пример кода (Python):**
```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        # Последние i элементов уже отсортированы, их можно не проверять
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        # Если не было перестановок, массив отсортирован
        if not swapped:
            break
    return arr
```

### 2. Сортировка Вставками (Insertion Sort)

**Принцип работы:**  
Массив условно делится на отсортированную и неотсортированную части. На каждом шаге берется первый элемент из неотсортированной части и «вставляется» на правильное место в отсортированную часть, сдвигая большие элементы вправо. Это аналогично тому, как человек сортирует карты в руке, раскладывая их по порядку одну за другой.

**Характеристики:**
*   **Лучшее время:** $O(n)$ (если массив уже отсортирован)
*   **Среднее время:** $O(n^2)$
*   **Худшее время:** $O(n^2)$ (массив отсортирован в обратном порядке)
*   **Память:** $O(1)$
*   **Устойчивость:** Да

**Пример кода (Python):**
```python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i] # Элемент, который нужно вставить
        j = i - 1
        # Сдвигаем элементы, которые больше key, на одну позицию вправо
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr
```
*Примечание:* Сортировка вставками является одной из самых эффективных квадратичных сортировок на практике для маленьких массивов ($n < 50$) или почти отсортированных данных.

### 3. Сортировка Выбором (Selection Sort)

**Принцип работы:**  
Алгоритм делит массив на отсортированную и неотсортированную части. На каждом шаге он находит **минимальный** (или максимальный) элемент в неотсортированной части и меняет его местами с первым элементом неотсортированной части (который становится последним элементом отсортированной части).

**Характеристики:**
*   **Лучшее время:** $O(n^2)$ (алгоритм всегда выполняет полный поиск минимума, даже если массив уже отсортирован)
*   **Среднее время:** $O(n^2)$
*   **Худшее время:** $O(n^2)$
*   **Память:** $O(1)$
*   **Устойчивость:** **Нет** (при обмене элементов местами относительный порядок равных элементов может нарушиться. Например, в массиве `[4, 4*, 2]` первая `4` поменяется местами с `2`, и порядок `4` и `4*` изменится).

**Пример кода (Python):**
```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        # Предполагаем, что минимальный элемент находится на позиции i
        min_idx = i
        # Ищем истинный минимальный элемент в оставшейся части
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        # Меняем найденный минимальный элемент с первым элементом неотсортированной части
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr
```
