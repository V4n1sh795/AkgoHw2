Структура данных **Очередь (Queue)** — это линейная структура данных, которая работает по принципу **FIFO** (First In, First Out / «Первым пришел — первым ушел»). 

---
### Основные операции очереди

Любая корректная реализация очереди должна поддерживать следующие операции (в идеале все они должны выполняться за время **O(1)**):

1. **`enqueue(item)`** (или `push`): Добавить новый элемент в **конец** (хвост) очереди.
2. **`dequeue()`** (или `pop`): Удалить и вернуть элемент из **начала** (головы) очереди.
3. **`peek()`** (или `front`): Вернуть значение элемента в начале очереди, **не удаляя** его.
4. **`is_empty()`**: Проверить, пуста ли очередь (возвращает `True` или `False`).
5. **`size()`**: Вернуть текущее количество элементов в очереди.

---

### 1. Реализация без связного списка (на основе массива)

Простая реализация на основе обычного массива неэффективна: при удалении элемента из начала (`dequeue`) либо придется сдвигать все остальные элементы влево (что дает сложность **O(N)**), либо указатель начала будет двигаться вправо, оставляя неиспользуемую («дырявую») память слева.

Чтобы решить эту проблему, используют **Кольцевую очередь (Circular Queue)**. В ней индексы начала (`front`) и конца (`rear`) «заворачиваются» по кругу с помощью операции взятия остатка от деления (`%`).
#### Пример реализации на Python (Кольцевая очередь):

```python
class CircularQueue:
    def __init__(self, capacity):
        self.capacity = capacity
        self.queue = [None] * capacity
        self.front = 0      # Индекс первого элемента
        self.rear = -1      # Индекс последнего элемента
        self.size = 0       # Текущее количество элементов

    def is_empty(self):
        return self.size == 0

    def is_full(self):
        return self.size == self.capacity

    def enqueue(self, item):
        if self.is_full():
            raise OverflowError("Очередь заполнена")
        # Двигаем rear по кругу
        self.rear = (self.rear + 1) % self.capacity
        self.queue[self.rear] = item
        self.size += 1

    def dequeue(self):
        if self.is_empty():
            raise IndexError("Очередь пуста")
        item = self.queue[self.front]
        # Двигаем front по кругу
        self.front = (self.front + 1) % self.capacity
        self.size -= 1
        return item

    def peek(self):
        if self.is_empty():
            raise IndexError("Очередь пуста")
        return self.queue[self.front]
```
*Примечание:* Если использовать динамический массив (как `list` в Python или `vector` в C++), можно реализовать очередь с автоматическим изменением размера, но операция изменения размера будет занимать **O(N)** времени (амортизированно **O(1)**).

**Сложность:**
* Время: `enqueue` — O(1), `dequeue` — O(1), `peek` — O(1).
* Память: O(N), где N — максимальная емкость (capacity). Нет накладных расходов на указатели, отличная локальность кэша процессора.

### 2. Реализация через связный список (Linked List)

Этот подход лишен проблемы фиксированного размера массива. Мы создаем узлы (Nodes), где каждый узел хранит данные и ссылку на следующий узел. 
Для обеспечения сложности **O(1)** при обеих основных операциях мы храним **два указателя**:
* `head` (голова) — указывает на первый элемент (отсюда будем удалять).
* `tail` (хвост) — указывает на последний элемент (сюда будем добавлять).

#### Пример реализации на Python:

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedListQueue:
    def __init__(self):
        self.head = None  # Начало очереди
        self.tail = None  # Конец очереди
        self._size = 0

    def is_empty(self):
        return self.head is None

    def enqueue(self, item):
        new_node = Node(item)
        if self.tail is None: 
            # Если очередь пуста, новый элемент становится и головой, и хвостом
            self.head = self.tail = new_node
        else:
            # Добавляем новый элемент после текущего хвоста и обновляем указатель tail
            self.tail.next = new_node
            self.tail = new_node
        self._size += 1

    def dequeue(self):
        if self.is_empty():
            raise IndexError("Очередь пуста")
        
        item = self.head.data
        self.head = self.head.next
        
        # Если после удаления очередь стала пустой, обнуляем и tail
        if self.head is None:
            self.tail = None
            
        self._size -= 1
        return item

    def peek(self):
        if self.is_empty():
            raise IndexError("Очередь пуста")
        return self.head.data

    def size(self):
        return self._size
```

**Сложность:**
* Время: `enqueue` — O(1), `dequeue` — O(1), `peek` — O(1).
* Память: O(N), где N — текущее количество элементов. Есть небольшие накладные расходы на хранение указателя `next` в каждом узле, и худшая локальность данных в кэше по сравнению с массивом.

---

### Сравнение подходов

| Характеристика | Кольцевая очередь (Массив) | Связный список |
| :--- | :--- | :--- |
| **Размер** | Фиксированный (или с дорогим ресайзом) | Динамический (растет по мере необходимости) |
| **Память** | Экономная (нет указателей), но может быть простаивающая емкость | Расходует доп. память на хранение указателей (`next`) |
| **Скорость (Cache)** | Высокая (элементы лежат в памяти подряд) | Ниже (узлы разбросаны по куче) |
| **Когда использовать** | Когда известен максимальный размер очереди или критична производительность и работа с кэшем (например, в embedded-системах). | Когда размер очереди заранее неизвестен и может сильно колебаться. |
