**Сортировка слиянием (Merge Sort)** — это эффективный алгоритм сортировки, основанный на парадигме «разделяй и властвуй». Он гарантирует стабильную работу и предсказуемую скорость, что делает его одним из самых надежных алгоритмов сортировки.
### Как это работает?
Алгоритм состоит из двух основных этапов:
1. **Разделение (Divide)**: Исходный массив рекурсивно делится пополам, пока не будут получены подмассивы длиной в 1 элемент. Массив из одного элемента считается уже отсортированным.
2. **Слияние (Conquer/Combine)**: Отсортированные подмассивы последовательно объединяются (сливаются) в новые отсортированные массивы до тех пор, пока не будет получен один полный отсортированный массив.
### Пример реализации на Python

```python
def merge_sort(arr):
    # Базовый случай рекурсии: массив из 0 или 1 элемента уже отсортирован
    if len(arr) <= 1:
        return arr
    
    # Находим середину массива
    mid = len(arr) // 2
    
    # Рекурсивно сортируем левую и правую половины
    left_half = merge_sort(arr[:mid])
    right_half = merge_sort(arr[mid:])
    
    # Сливаем две отсортированные половины
    return merge(left_half, right_half)

def merge(left, right):
    sorted_array = []
    i = j = 0
    
    # Сравниваем элементы из обеих половин и добавляем меньший в результат
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            sorted_array.append(left[i])
            i += 1
        else:
            sorted_array.append(right[j])
            j += 1
            
    # Добавляем оставшиеся элементы (если они есть)
    sorted_array.extend(left[i:])
    sorted_array.extend(right[j:])
    
    return sorted_array

# Пример использования:
data = [38, 27, 43, 3, 9, 82, 10]
print("Исходный массив:", data)
print("Отсортированный массив:", merge_sort(data))
```
### Характеристики алгоритма

| Характеристика | Значение |
| :--- | :--- |
| **Временная сложность (лучший случай)** | $O(n \log n)$ |
| **Временная сложность (средний случай)** | $O(n \log n)$ |
| **Временная сложность (худший случай)** | $O(n \log n)$ |
| **Пространственная сложность** | $O(n)$ (требует дополнительной памяти) |
| **Стабильность** | **Да** (относительный порядок равных элементов сохраняется) |

### Преимущества и недостатки

**Преимущества:**
- **Предсказуемость**: Время работы всегда $O(n \log n)$, в отличие от быстрой сортировки (Quick Sort), которая в худшем случае может деградировать до $O(n^2)$.
- **Стабильность**: Идеально подходит для сортировки объектов по нескольким ключам (например, сначала по возрасту, потом по имени).
- **Эффективность на связанных списках**: Не требует случайного доступа к элементам, поэтому отлично работает со связными списками без дополнительных затрат памяти $O(n)$.

**Недостатки:**
- **Дополнительная память**: Требует $O(n)$ дополнительной памяти для создания временных массивов при слиянии (в стандартной реализации).
- **Накладные расходы**: На небольших массивах может работать медленнее, чем быстрая сортировка или сортировка вставками, из-за рекурсивных вызовов и операций с памятью.
### Когда использовать?
- Когда важна **стабильность** сортировки.
- Когда нужно гарантировать время выполнения $O(n \log n)$ в худшем случае (например, в системах реального времени).
- При сортировке больших объемов данных, которые не помещаются в оперативную память (внешняя сортировка, где данные читаются с диска частями).
