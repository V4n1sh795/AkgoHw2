*Структура данных Стек(Stack). Основные операции. Реализация через связный список и без него.*
    **Стек (Stack)** — это линейная структура данных, которая работает по принципу **LIFO** (Last In, First Out — «последним пришел, первым ушел»).
	**Операции:**
	- **`push(x)`** (добавление / проталкивание): добавляет элемент `x` на вершину стека.
	- **`pop()`** (извлечение / выталкивание): удаляет и возвращает элемент с вершины стека. Если стек пуст, обычно выбрасывается исключение (ошибка).
	- **`peek()`** или **`top()`** (просмотр): возвращает элемент с вершины стека, **не удаляя** его.
	- **`is_empty()`** (проверка на пустоту): возвращает `True`, если в стеке нет элементов, и `False` в противном случае.
	- **`size()`** (размер): возвращает количество элементов в стеке.
	**Реализации:**
	- На основе массива
		`list.append()` - последний элемент - это голова массива 
		`Проблема` -  в худшем случае добавление за O(n)
	- На основе LinkedList:
		В этой реализации каждый элемент стека представлен узлом (Node), который хранит данные и ссылку на следующий узел. Вершина стека — это **голова (head)** связного списка.
		`гарант по скорости` - O(n)
		`память на указатели`
